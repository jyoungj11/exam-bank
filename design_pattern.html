정보처리기사 디자인 패턴 암기법

전체 암기 키워드: 생구행 (학생을 구해요! ➔ 학생구행)

1. 생성 패턴 (Creational)

💡 "추성훈은 빌더 같은 몸을 지닌 싱글 프로인 것은 팩트이다"
추성훈 - Abstract Factory - 추상 팩토리 (의존하지 않고, 조합을 만드는, 인터페이스 제공)
빌더 - Builder - 빌더 (생성과 표기를 분리, 복잡한 객체 생성)
싱글 - Singleton - 싱글톤 (하나만 생성)
프로 - Prototype - 프로토타입 (원형을 만들어 놓고, 필요한 부분 수정)
팩트 - Factory Method - 팩토리 메소드 (하위 인스턴스 생성, 상위 인스턴스 결정, 오버로딩)

2. 구조 패턴 (Structural)

💡 "컴포즈 커피에 가기 위해 브리지를 건넙니다. 건너서 꽃으로 장식해 확싸게 판매하는 커피를 플렉스하고 어댑터가 있는 자리에 앉아 마십니다."
컴포즈 - Composit - 컴포지트 (부분-전체, 복합객체와 단일객체 동일하게 취급)
브리지 - Bridge - 브릿지 (계층 연결, 독립적으로 확장)
꽃(플라워) - Flyweight - 플라이웨이트 (메모리 절약, 클래스 경량화)
장식 - Decorator - 데코레이터 (그때그때 필요한 기능 추가, 유연하게 확장)
확싸게 - Facade - 파사드 (결합도 낮춤, 단순화)
플렉스 - Proxy - 프록시 (용량 아낌, 정보 은닉)
어댑터 - Adapter - 어댑터 (함께 이용할 수 있도록, 인터페이스를 기존 인터페이스에 덧씌움)

3. 행위 패턴 (Behavioral)

💡 "메멘토 상태로 주인공이 병원에 방문하였더니 중재자가 나타나 책임을 지고 주인공을 돕기로 합니다. 테블릿을 꺼내 서버로 들어가 전략을 세운 후에 프린트하여 주인공에게 반복시켜줍니다."
메멘토 - Memento - 메멘토 (저장할 필요가 있을 때, undo 기능 요청)
상태 - State - 상태 (캡슐화, 클래스화, 원시 코드 수정 최소화)
방문 - Visitor - 방문자 (각 클래스를 돌아다니며 특정 작업 수행)
중재자 - Mediator - 중재자 (상호작용의 유연한 변경 지원)
책임 - Chain of Responsibility - 책임 연쇄 (정적 하드코딩, 동적으로 연결)
태블릿 - Template Method - 템플릿 메소드 (상위 작업 구조 X, 서브 클래스로 작업 일부분 수행)
서버 - Observer - 옵저버 (객체 상태 변화를 다른 객체로 전달)
전략 - Strategy - 전략 (동적으로 행위를 자유롭게 변환)
프린트 - Interpreter - 인터프리터 (언어 해석)
반복 - Iterator - 반복자 (내부구조 노출 X, 복잡 객체 순차적 접근)
출처: 행복은 내곁에 네이버 블로그
