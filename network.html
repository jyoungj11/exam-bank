네트워크 주요 IP 및 부가 기술 이론

정보처리기사 실기 시험에 자주 출제되는 핵심 네트워크 프로토콜 및 기술 정리입니다.

1. NAT (Network Address Translation, 네트워크 주소 변환)

개념: 사설 IP 주소를 공인 IP 주소로 변환해주는 네트워크 기술입니다.

주요 특징:

  • 부족한 IPv4 공인 주소를 효율적으로 고갈 없이 사용할 수 있게 해줍니다.
  • 내부 네트워크의 사설 IP를 숨길 수 있어 **보안성 향상** 효과가 있습니다.
2. DNS (Domain Name System, 도메인 이름 시스템)

개념: 사람이 읽기 쉬운 도메인 이름(예: www.example.com)을 컴퓨터가 이해할 수 있는 IP 주소(예: 192.0.2.1)로 변환해 주는 시스템입니다.

주요 특징:

  • 계층적인 분산 데이터베이스 구조로 이루어져 있습니다.
  • 기본적으로 UDP 53번 포트를 사용합니다. (영역 전송 등 대용량 데이터는 TCP 사용)
3. QoS (Quality of Service, 서비스 품질)

개념: 네트워크 트래픽 우선순위를 지정하여, 데이터 유실이나 지연(Latency)에 민감한 서비스(예: 실시간 음성 통화, 동영상 스트리밍)에 일정한 수준의 성능을 보장해 주는 기술입니다.

주요 관리 지표: 대역폭(Bandwidth), 지연 시간(Latency), 패킷 손실률(Packet Loss) 등

4. VPN (Virtual Private Network, 가상 사설 통신망)

개념: 공중 네트워크(인터넷)를 마치 전용선처럼 사용하여 안전하게 데이터를 주고받을 수 있도록 암호화 터널링 기술을 제공하는 네트워크 기술입니다.

주요 특징: IPsec, SSL/TLS 등의 프로토콜을 기반으로 데이터를 암호화하여 외부 감청이나 해킹으로부터 보호합니다.

5. DHCP (Dynamic Host Configuration Protocol, 동적 호스트 구성 프로토콜)

개념: 네트워크에 접속하는 호스트(PC, 스마트폰 등)에게 IP 주소, 서브넷 마스크, 게이트웨이 주소 등을 **자동으로 할당**해 주는 프로토콜입니다.

주요 특징:

  • 관리자가 수동으로 일일이 IP를 설정할 필요가 없어 관리가 편리합니다.
  • IP 주소 충돌을 방지하고 유휴 IP를 효율적으로 회수 및 재할당할 수 있습니다.
