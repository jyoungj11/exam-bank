정보처리기사 핵심 이론 기출 모음

2020년 ~ 2026년 1회차 주요 출제 이론 재검토 완벽 정리

2020년

웹브라우저 간 HTML 문법이 호환되지 않는 문제와 SGML의 복잡함을 해결하기 위하여 개발된 다목적 마크업 언어
답: XML
속성-값 쌍으로 이루어진 데이터 오브젝트를 전달하기 위해 사용하는 개방형 표준 포맷. AJAX에서 많이 사용되며 XML을 대체함.
답: JSON
128비트 암호화 해시 함수 (RFC 1321). 파일 무결성 검사에 사용되며 MD4를 대체하기 위해 로널드 라이베스트가 고안함.
답: MD5
패킷의 출발지 주소와 포트를 임의로 변경하여 출발지와 목적지 주소를 동일하게 함으로써 서비스 거부 상태를 유도하는 공격
답: 랜드 어택 (Land Attack)
비동기식 자바스크립트 XML. 페이지 전체 새로고침 없이 필요한 일부만 로딩하여 대화식 웹 애플리케이션을 제작하는 기법
답: AJAX
요구사항 변화에 유연하게 대응하기 위해 일정한 주기를 반복하며 시제품을 지속적으로 제공하는 소규모 프로젝트 중심의 방법론
답: 애자일 (Agile)
한 객체의 상태가 바뀌면 의존하는 다른 객체들에 연락이 가고 자동 갱신되는 1대 다 의존성을 가지는 느슨한 결합 디자인 패턴
답: Observer 패턴
HTTP 등 프로토콜을 이용하여 XML 기반 메시지를 교환하는 프로토콜 (Envelope-Header-Body 구성). RESTful로 대체 가능
답: SOAP
소프트웨어 무결성 유지 및 식별, 편성, 수정 통제를 위한 프로세스. (도구: CVS, SVN, Clear Case 등)
답: 형상관리 (Configuration Management)
IP 패킷에서 외부 공인 IP/포트 주소를 내부 IP 주소로 재기록하여 라우터를 통해 트래픽을 주고받는 기술
답: NAT (Network Address Translation)
P2P 기반 분산 데이터 저장 환경에 관리 대상 데이터를 저장하여 누구도 임의로 수정할 수 없는 데이터 위변조 방지 기술
답: 블록체인
일반 PC급 컴퓨터들로 대형 스토리지를 형성하고 거대한 데이터 세트를 병렬 처리할 수 있는 오픈 소스 분산 컴퓨팅 프레임워크
답: 하둡 (Hadoop)

2021년

물리 네트워크(MAC) 주소에 해당하는 IP 주소를 알려주는 역순 주소 결정 프로토콜
답: RARP
웹 서비스명, 제공 위치, 메시지 포맷, 프로토콜 정보 등 웹 서비스 상세 정보가 기술된 XML 형식의 언어
답: WSDL
성능 향상과 개발 운영의 단순화를 위해 정규화된 데이터 모델에 중복, 통합, 분리를 수행하는 기법
답: 반정규화 (Denormalization)
모듈 간 통신 방식을 구현하기 위한 인터페이스 집합 (공유 메모리, 소켓, 세마포어, 파이프, 메시지 큐잉 등)
답: IPC (Inter-Process Communication)
서로 다른 플랫폼 및 애플리케이션 간의 정보 전달, 연계, 통합을 가능하게 해주는 솔루션 (Point to Point, Hub & Spoke 등)
답: EAI
개인 또는 그룹 식별자에 기반을 두며, 사용자가 다른 사용자에게 자신의 판단에 따라 권한을 허용하는 접근제어 방식
답: DAC (Discretionary Access Control)
정상 연결을 RST 패킷으로 종료시킨 후 재연결 시 희생자가 아닌 공격자에게 연결하여 세션을 가로채는 공격 기법
답: 세션 하이재킹 (Session Hijacking)
네트워크 장치 없이 토폴로지가 동적으로 변화하며 긴급 구조나 군사 네트워크에 활용되는 무선 네트워크
답: 애드혹 네트워크 (Ad-hoc Network)
NIST에서 개발, DES를 대체하는 128비트 블록 크기와 128/192/256비트 키 크기의 대칭 키 암호화 방식
답: AES
접근한 데이터에 대한 연산을 모두 마칠 때까지 상호 배제하는 병행 제어 기법
답: 로킹 (Locking)
상향식 테스트 시 상위 모듈 역할을 대신하는 테스트 드라이버와, 하향식 테스트 시 하위 모듈 역할을 대신하는 테스트 (____)
답: 스텁 (Stub)
ARP 메시지를 이용하여 근거리 통신망 하에서 상대방 데이터 패킷을 중간에서 가로채는 중간자 공격 기법
답: ARP 스푸핑
도메인 안의 개념 등 추상적 개념을 기술하며 속성과 메서드를 포함하는 다이어그램
답: 클래스 다이어그램 (Class Diagram)
자식 클래스가 어떤 객체를 생성할지를 결정하도록 하여 구체 클래스 이름을 감추는 패턴
답: 팩토리 메서드 (Factory Method) 패턴
시스템 접근 전 신원 검증(1), 권한 허용(2), 사용 정보 수집(3)의 보안 3요소
답: (1) Authentication (2) Authorization (3) Accounting

2022년

두 개 이상의 하드디스크를 병렬 연결해 스트라이프 방식으로 I/O 속도를 높이지만 디스크 고장 시 데이터 사용이 불가능한 기술
답: RAID-0
데이터베이스 복구 시 오류 전까지의 로그를 기록해 이전 상태로 되돌린 후 재실행하는 기법과 로그로 취소하는 기법
답: 1. Redo 2. Undo
소스 코드 실행 없이 의미를 분석해 결함을 찾는 기법(1)과, 코드를 실행하여 메모리 누수 등을 추적하는 기법(2)
답: 1. 정적 분석 기법 2. 동적 분석 기법
웹사이트를 미리 감염시킨 뒤 잠복하다가 방문 시 악성코드를 설치하는 APT 공격 방식
답: 워터링 홀 (Watering Hole)
클라이언트가 자신이 이용하지 않는 메서드에 의존하지 않아야 하며, 큰 인터페이스를 작게 분리해야 한다는 원칙
답: ISP (Interface Segregation Principle)
인터넷을 통해 디바이스 간에 사설 네트워크 연결을 생성하고 익명으로 데이터를 안전하게 전송하는 기술
답: VPN (Virtual Private Network)
대형 다중 사용자 시스템의 로그를 통합 관리 및 분석하여 위협에 사전에 대응하는 보안 솔루션
답: SIEM
프로세서 안에 독립적인 보안 구역을 두어 중요한 정보를 보호하는 ARM사의 하드웨어 기반 보안 기술
답: Trustzone
유명 도메인의 철자를 실수하는 것을 이용해 미리 유사한 도메인을 등록하는 공격 (URL 하이재킹)
답: 타이포스쿼팅 (Typosquatting)
하나의 사용자 정보 기반으로 여러 시스템에 하나의 통합 인증을 사용하게 하는 방법
답: SSO (Single Sign-On)

2023년

2계층(데이터링크 계층)에서 구현되는 터널링 기술. L2F와 PPTP가 결합된 프로토콜
답: L2TP
TCP/IP에서 IP 패킷 처리 문제를 알리며 ping 명령어 등을 통해 네트워크 이상 유무를 확인하는 프로토콜
답: ICMP
복잡한 시스템에서 내부 객체 관계를 단순화하고 외부에서는 세부 내용을 숨기는 대리 패턴
답: Proxy 패턴
소프트웨어 불법 변경 시 정상 수행되지 않도록 변조검증코드를 삽입하는 역공학 방지 기법
답: 템퍼 프루핑 (Tamper-proofing)
대칭키 알고리즘 종류와 비대칭키 알고리즘 종류
답: 대칭키(DES, AES, ARIA, SEED) / 비대칭키(RSA, ECC)
임의 크기 데이터를 고정 크기 데이터로 변환하여 O(1)의 매우 빠른 평균 시간 복잡도를 가지는 자료구조/함수
답: 해시 (Hash)
타사 앱이 사용자 자격 증명 공유 없이 리소스 접근 권한을 위임받을 수 있는 개방형 표준 프로토콜 (권한 위임)
답: OAuth
고정 길이 패킷(셀, 53바이트)을 이용하여 처리가 단순하고 고속망에 적합한 가상 채널 기반 전송 방식
답: ATM (Asynchronous Transfer Mode)
최소 Hop count를 파악하여 경로를 결정하는 거리 벡터(Distance Vector) 기반의 내부 라우팅 프로토콜
답: RIP

2024년

링크 상태를 감시하여 최적의 경로를 선택하며 최단 경로 산정에 다익스트라(Dijkstra) 알고리즘을 사용하는 프로토콜
답: OSPF
조인 조건이 정확히 '='로 일치하며 중복 속성을 제거한 결과를 반환하는 조인
답: 자연 조인 (Natural Join)
인터넷 공격자의 존재를 숨기면서 시스템에 무제한 접근 권한을 부여하는 악성 프로그램 (시스템콜 해킹 등 우회)
답: 루트킷 (Rootkit)
구체적인 클래스에 의존하지 않고 서로 연관되거나 의존적인 객체들의 조합을 만드는 인터페이스를 제공하는 패턴 (Kit이라고도 함)
답: Abstract Factory 패턴
네트워크 계층에서 IP 패킷을 암호화하고 인증하는 VPN 구현 표준 프로토콜 (AH, ESP 사용)
답: IPSec
한 모듈 내부의 한 기능 요소에 의한 출력 자료가 다음 기능 요소의 입력 자료로 제공되는 응집도 형태
답: 순차적 응집도 (Sequential Cohesion)
컬렉션 객체의 내부 구조를 노출하지 않고 순차적으로 접근할 수 있게 하는 패턴 (Cursor라고도 함)
답: Iterator 패턴
송신 주소를 공격 대상 IP로 위장하여 네트워크 라우터 브로드캐스트 주소로 설정하고 과부하시키는 공격
답: 스머핑 (Smurfing)

2025년

데이터를 전송하거나 저장할 때 오류를 감지하기 위해 다항식 나눗셈을 기반으로 나머지를 검사값으로 삼는 오류 검출 코드
답: CRC (Cyclic Redundancy Check)
공포심(불안, 위협)을 유발하여 사용자가 원치 않는 소프트웨어를 구매하거나 대가를 지불하도록 속이는 악성 소프트웨어
답: 스어웨어 (Scareware)
원격 접속 보안 프로토콜로 공개키 기반 인증 및 암호화된 데이터 전송을 지원하며 기본 포트 22번을 사용하는 기술
답: SSH
CPU burst 시간이 짧은 프로세스를 우선 처리하는 스케줄링 방식(1)과, 이를 선점형으로 구현한 형태(2)
답: (1) SJF (2) SRT
전송 데이터에 여러 검사 비트를 추가하여 오류 검출뿐만 아니라 **수정**까지 가능한 재전송 없는 자체 수정 방식
답: 해밍 코드 (Hamming Code) / FEC (방식)
매번 새로운 값을 생성하고 해시 함수를 이용해 평문을 저장하지 않고 유효성을 확인하여 재전송 공격을 방지하는 일회성 인증
답: OTP (One-Time Password)

2026년 (최신 기출 복원)

1. 시스템 운영 중 로그 관리 및 모니터링 기능을 제공해야 한다. 2. 시스템 운영 시 최소 메모리 용량을 확보해야 하며, 자원 사용량은 제한 범위 내에 있어야 한다. 3. 사용자 요청에 대한 응답 시간은 최대 1분을 초과하지 않아야 한다. (보기: 신뢰성, 가용성, 운영, 유지보수성, 자원, 성능, 이식성, 보안, 품질 중 선택)
답: 1. 운영 2. 자원 3. 성능
• (ㄱ) 패턴은 기능의 클래스 계층과 구현의 클래스 계층을 연결 • (ㄴ) 패턴은 한 객체의 상태가 바뀌면 그 객체에 의존하는 다른 객체들에 연락이 감
답: (ㄱ) Bridge (ㄴ) Observer
정보보호 관리체계 용어의 영문 약자
답: ISMS
1. 실제 사용자 데이터를 전송하는 프레임 2. 데이터 링크의 흐름 제어, 오류 제어, 상태 감시 프레임 3. 순서 번호 없이 링크 설정, 해제, 모드 설정 등 제어 기능을 수행하는 프레임 4. 두 국(Station)이 동등한 위치에서 서로 명령과 응답을 주고받는 모드 5. 종국(Secondary)이 주국(Primary) 허가 없이 자발적 응답을 전송하는 모드
답: 1. 정보 프레임 2. 감독 프레임 3. 비번호 프레임 4. 비동기 균형 모드(ABM) 5. 비동기 응답 모드(ARM)
원본 데이터 파일은 별도로 존재하고, 공격자가 해당 파일의 경로를 가리키는 특수 파일을 생성해두었다가, 프로그램이 임시 파일을 생성하는 순간 교체하여 오동작을 유도하는 취약점 공격
답: 심볼릭 링크 (Symbolic Link) 취약점
공격자가 자주 방문하는 합법적인 웹사이트를 사전에 파악해 악성코드를 삽입하고, 피해자가 접속하는 순간 감염되도록 특정 대상을 겨냥하는 공격
답: 워터링 홀 (Watering Hole)
