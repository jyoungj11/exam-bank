문제 20. 정보보안 암호화 알고리즘 (해시 함수)

데이터 무결성 검증을 위해 임의 길이의 입력 데이터를 고정된 길이(예: 128비트 또는 160비트 등)의 값으로 변환해 주는 단방향 암호화 알고리즘(해시 함수)의 일종으로, MD5의 결점을 보완하여 널리 사용되는 대표적인 해시 알고리즘 영문 약자를 쓰시오.

정답 및 해설 모음

문항 정답 해설
1번 20
삼항 연산자 조건식(`10 > 20`)이 거짓이므로 변수 b의 값인 20이 선택되어 출력됩니다.
2번 10, 20
ptr이 1칸 증가하여 arr[1](값 10)을 가리키므로 *ptr은 10, *(ptr+2)는 arr[3](값 20)이 됩니다.
3번 Builder (빌더 패턴)
객체 생성 과정을 분리하여 동일한 절차로 서로 다른 표현을 만드는 빌더 패턴입니다.
4번 Low
strcmp("Apple", "Banana")는 'A'와 'B'의 아스키코드 비교 결과 음수를 반환하므로 "Low"가 출력됩니다.
5번 Shadow Page Table (그림자 페이지 테이블)
섀도 페이징 회복 기법에서 트랜잭션 수행 시 백업 용도로 사용하는 페이지 테이블입니다.
6번 C-SCAN (Circular SCAN)
한쪽 방향으로만 헤드가 이동하며 요청을 처리하고 끝에 도달하면 반대편 끝으로 즉시 돌아가는 디스크 스케줄링입니다.
7번 (조건에 부합하는 행 개수)
부서별 평균 급여가 3500 이상인 그룹의 총 개수입니다.
8번 10
재귀 함수 호출 결과 4 + 3 + 2 + 1 = 10이 계산되어 출력됩니다.
9번 SMTP
메일 송수신을 위한 표준 프로토콜로 TCP 25번 포트를 사용합니다.
10번 전역 결합도 (Global Coupling) 또는 공통 결합도
전역 변수를 공유하여 발생하는 결합도 형태입니다.
11번 (LEFT OUTER JOIN 결과)
왼쪽 테이블의 모든 행과 우측 테이블의 일치하는 행을 조인한 결과입니다.
12번 C
다형성에 의해 자식 클래스(Child)에서 오버라이딩된 show() 메서드가 실행되어 "C"가 출력됩니다.
13번 XSS (Cross-Site Scripting)
악성 스크립트를 웹 페이지에 삽입하여 실행하는 대표적인 웹 취약점입니다.
14번 254개
클래스 C 네트워크의 호스트 비트는 8개($2^8 - 2 = 254$)이며, 네트워크 및 브로드캐스트 주소를 제외한 사용 가능 IP 수는 254개입니다.
15번 순차적 응집도 (Sequential Cohesion)
이전 구성 요소의 출력이 다음 구성 요소의 입력으로 순차적으로 전달되는 응집도입니다.
16번 10
2차원 배열의 모든 요소(1 + 2 + 3 + 4)의 총합인 10이 누적 출력됩니다.
17번 조건 커버리지 (Condition Coverage)
조건식 내부의 개별 조건이 참과 거짓을 모두 갖도록 검증하는 기법입니다.
18번 20
동적 바인딩에 의해 자식 클래스(Derived)의 오버라이딩된 getNum()이 호출되어 20이 출력됩니다.
19번 20
lambda 식에 4와 5를 전달하여 곱셈 연산 결과인 20이 출력됩니다.
20번 SHA (또는 SHA-1, SHA-256)
MD5의 결점을 보완하여 널리 사용되는 대표적인 단방향 해시 암호화 알고리즘입니다.
